01The pipeline

The headset samples head and hands at 72–90 Hz. Every half second it sends one second of motion and any game events. The API turns each window into measurements and discards the raw samples, then pushes the result to your dashboard over Supabase Realtime.

  1. HeadsetHead + both controllers, pose per frame, plus game events.
  2. IngestPer-session token. Refused until the candidate consents.
  3. QS features4–12 Hz band energy, head scanning, low motion, startle, timing.
  4. PostgresOne row per window. Row-level security per employer.
  5. RealtimePrivate broadcast channel per session.
  6. YouThis page. Pseudonymous ids only.
